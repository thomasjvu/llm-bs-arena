\section{Reproducibility and Dataset Hygiene}

The frozen comparable cohort contains 600 winner-terminated games with no mixed-cohort or turn-cap exclusions. The tracked frozen artifact directory for this submission contains:
\begin{itemize}[leftmargin=1.25em]
  \item \texttt{artifacts/frozen/cohort\_manifest.json}
  \item \texttt{artifacts/frozen/player\_game\_stats.csv}
  \item \texttt{artifacts/frozen/player\_stats\_exp0.csv} through \texttt{player\_stats\_exp3.csv}
  \item \texttt{artifacts/frozen/research\_summary.md}
\end{itemize}

\subsection{Execution}

\begin{itemize}[leftmargin=1.25em]
  \item seeded deck order and seeded seating
  \item fixed prompt version \texttt{2026-03-26} and prompt hash \texttt{p1939995863}
  \item single-provider cohort using NVIDIA NIM for the main pilot
  \item uncapped winner-terminated research-default runs
  \item six-model roster with all $\binom{6}{4}=15$ unique four-model matchups
  \item ten games per matchup per experiment for Experiments~0, 1, 2, and~3
\end{itemize}

\subsection{Failure Recovery}

\begin{itemize}[leftmargin=1.25em]
  \item structured-response retries
  \item provider client recreation on recoverable failures
  \item shard checkpoints and active snapshots
  \item exclusion of capped and mixed-cohort runs from the main analysis
\end{itemize}

\subsection{Analysis Cohort}

The default analysis cohort includes only logs that satisfy all of:
\begin{itemize}[leftmargin=1.25em]
  \item current schema version
  \item current provider cohort
  \item current prompt version and prompt hash
  \item \texttt{terminationReason = "winner"}
  \item not located in quarantine folders
\end{itemize}

Runs with \texttt{terminationReason = "turn\_cap"} are treated as censored and excluded from the main paper cohort. Mixed-cohort and legacy logs are excluded by dominant-cohort filtering at analysis time.

\subsection{Reproduction Steps}

Minimum reproduction steps:
\begin{enumerate}[leftmargin=1.5em]
  \item Install Node and Python dependencies.
  \item Configure a current NVIDIA API key.
  \item Verify provider availability and the six-model roster.
  \item Run one logged validation game.
  \item Run the desired tournament shards.
  \item Export CSVs and generate stats, plots, and the markdown research brief.
\end{enumerate}
