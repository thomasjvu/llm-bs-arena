\section{Appendix Material}
The appendix material for submission is split into the blinded supplement, the tracked frozen artifacts, and the versioned release metadata. The supplement contains the final prompt texts, reproducibility and cohort-hygiene details, additional results, and qualitative case studies. The tracked frozen artifact directory contains the frozen cohort manifest, summary-level CSVs, and markdown research brief used to prepare the submission. The versioned release directory contains the benchmark release manifest, dataset manifest, evaluation manifest, checksums, and release notes for the 600-game cohort.
